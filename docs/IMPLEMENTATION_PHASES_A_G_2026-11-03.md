[Types]

All JavaScript contracts use plain objects, explicit allowlisted fields, bounded strings/arrays, defensive copies and runtime validation. Document them with JSDoc; do not introduce TypeScript or a schema-library dependency. All serializable numerical values must be finite; nonfinite results become explicit failures, never JSON null substitutions. IDs use lower-case `[a-z0-9][a-z0-9_-]{1,63}` unless an existing contract requires otherwise. UUID bundle/run IDs use browser crypto or Python uuid, not timestamps alone. Unknown keys/schema versions fail closed.

1. `CameraBounds = {min:[x,y,z],max:[x,y,z]}` finite and ordered. `CameraFitOptions = {aspect,fovDegrees,padding}`: aspect >0, fov 1..120, padding 1..2. `CameraPose = {target:[x,y,z],offset:[x,y,z]}` remains compatible with `getCameraPose`. Bounds describe illustrative artwork, never physical dimensions. Fit all eight corners in camera space, honor near/far and OrbitControls distance limits, and exclude room/dome background from lab bounds.
2. `PresentationState = {scale,representation,quality,overlayIds,selectionId,cutPlane,motion}`. Scale: `laboratory|construct|cell|tissue-context`. Representation: `illustration|model-field`. Quality retains `low|balanced|high`. `overlayIds` contains at most four registered IDs; `selectionId` is null or known object ID; `cutPlane` is null or `{axis:'x'|'y'|'z',fraction:0..1}`; motion `system|reduced`. Defaults laboratory/illustration/balanced/no overlays/no selection/no plane/system. Store separately from scenario /13. Scale changes are discrete representational transitions, not a continuous physical zoom or a biological model.
3. `Quantity = {value,unit,origin,sourceIds,uncertainty,missingReason}`. Value finite number or null. Origins `synthetic|hypothetical|user-declared-measured|literature|derived`. Null value requires a nonempty missingReason; nonnull requires missingReason null. Uncertainty null or `{kind:'interval',lower,upper,unit}`, finite ordered endpoints in the quantity's exact unit, encompassing value; no confidence level invented. Up to 50 source IDs. Literature requires source references; derived requires run provenance. User-declared measured remains unverified. Unit allowlist initially `1`, `Pa`, `Pa*s`, `um`, `mm3/s`, `m2/s`, `mol/m3`, `mol/(m3*s)`, `h`, `relative-population`. No implicit conversion or geometry-unit assignment.
4. `DomainModelDefinition = {id,version,label,domain,inputDefinitions,outputDefinitions,assumptions,boundaryConditions,validityConditions,sourceIds,implementationId,couplingPolicy,supportedOperations}`. Version starts 1; definitions map stable field IDs to `{unit,type,min,max,nullable}` consistent with current validators. Coupling policies `independent|explicit-hypothetical-mapping`; operations bounded subset `evaluate|sweep|field`. Register storyboard, slab oxygen, box oxygen, flow resistance, nozzle shear, vascular supply and relative division. Cross-reference is an explicit mapping adapter, not a new physical coupling. Tissue atlas/hardware/recipe catalogs remain reference content, not runnable predictive models.
5. `ModelRun = {id,modelId,modelVersion,inputSnapshot,inputSha256,implementationSha256,startedAt,finishedAt,status,outputs,diagnostics,sourceIds,notices}`. Status `succeeded|out-of-domain|numerical-failure|cancelled|failed`. Digests lowercase SHA-256 of exact saved bytes; browser produces input canonical JSON bytes using recursively sorted keys and deterministic LF rules defined in the exchange document. Implementation digest covers ordered module names and per-file hashes of transitive evaluator dependencies, produced at verification time; if unavailable label provenance incomplete and disallow a pinned reproducibility claim. Output quantities cannot upgrade origin/review level.
6. `OverlayDefinition = {id,modelId,representation,unit,legend,coordinateSpace,requiresRun}`. CoordinateSpace `normalized-box|network|illustrative`. Slice fields only render on their normalized-box proxy, not painted onto scaffold geometry. Flow edges carry the original dimensionless notice; shear/supply outputs are labeled reference panels, not calibrated tissue fields. Selection exposes accessible text/table alternatives.
7. `SweepSpec = {modelId,baseInputs,axes,seed}`: 1–2 numeric axes, 2–10 explicitly listed unique finite values per axis, <=100 total points. Box oxygen initially limited to resolution <=17 and <=25 points. Reject categorical/structural sweeps unless explicitly supported later. Seed is uint32, only used where a model actually uses randomness. `SweepResult = {spec,points,summary,status}` with per-point inputs/status/run/error and completed/failed/total counts. Summary reports comparable same-unit ranges and finite-difference sensitivity only when valid points/comparable coordinates exist; no probability, causal effect, viability or efficacy ranking.
8. `HypothesisCard = {id,revision,title,question,scope,claimBoundary,status,system,mechanism,alternatives,predictions,falsifiers,confounders,missingMeasurements,modelIds,supportingEvidenceIds,contradictingEvidenceIds,queryPlanIds,parentHypothesisIds,authorship,reviewStatus}`. Revision positive integer; title <=300 chars, narrative fields <=3000; lists <=30 items <=500 chars; 2–8 alternatives `{id,prediction,falsifier}`. Status `draft|ready-for-review|archived`, reviewStatus `unreviewed|owner-reviewed`; neither means scientific validation. Authorship `{createdBy:'owner'|'agent'|'import',method,reviewedBy:null|string}`. Templates are deterministic prompts/candidates, never autonomous scientific discoveries. Missing predictions/falsifiers prevent ready-for-review; preserve drafts without fabricating values. Evidence IDs resolve to retained records, with source class/review state and exact locators.
9. `QueryPlan = {id,hypothesisId,query,providerIds,limit,purpose,disclosure,executionStatus}`. Query <=500 chars; 1–8 providers from verified Desk capabilities, limit 1..10. ExecutionStatus `planned|not-supported`; Workbench never queues a job. Local user text stays private unless explicitly selected for exchange; bibliography leads are unreviewed.
10. `ResearchExchangeBundle` schema `bioprinting-workbench/research-exchange/1`: `{schema,bundleId,createdAt,producer,sourceRevision,hypotheses,queries,modelRuns,evidence,artifacts,privacyClassification,publicationReviewStatus}`. Producer `{application,version,executedBy}`; sourceRevision `{commit:null|string,dirty:boolean,implementationSha256:null|string}`. Max manifest 5 MiB UTF-8, 100 hypotheses, 100 queries, 100 model runs, 500 evidence records, 500 artifact descriptors, nesting <=20 and bounded individual strings. Privacy `private|selected-for-exchange`; publicationReviewStatus always `not-approved` on import. No secret/private-note field, executable content or HTML.
11. `ArtifactDescriptor = {id,filename,mediaType,bytes,sha256,provenance}`: flat basename `[A-Za-z0-9][A-Za-z0-9_.-]{0,95}`, no dot segments, slash/backslash, drive prefix, percent-encoded separator or symlink. Allow `json|csv|md|png`, bytes <=10 MiB per file, <=25 MiB total selected files. Provenance binds model run/evidence IDs and producer, not an arbitrary URL. Select files individually; no ZIP extraction in v1. A manifest alone is metadata-only until every required selected artifact hash/size matches; import receipts distinguish descriptors from verified bytes. No automatic URL fetch or path opening.
12. `ExchangeImportPreview = {bundleSha256,creates,duplicates,conflicts,warnings,blockedReasons,expectedStoreSha256}`. Duplicate exact bundle ID+hash is idempotent; same ID/different hash is conflict. Reference graph must be closed and acyclic for hypothesis ancestry; unknown model IDs can be retained as unsupported foreign metadata but never executed or overlaid. Preview has no writes, submissions or network calls. Apply binds preview to current store hash and exact bundle bytes; stale preview rejects.
13. `RunReceipt = {id,queryPlanId,deskRunId,status,parameters,submittedAt,finishedAt,artifactIds,failures,submissionSha256}`. Status `planned|queued|running|succeeded|partial|failed|interrupted|submission-unknown`; preserve Desk statuses without calling interrupted failed. Ambiguous submission response is submission-unknown, never auto-retry. Integrity verification is not scientific validation.
