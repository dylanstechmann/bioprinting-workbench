[Types]

All contracts are plain objects with explicit allowlisted fields, bounded strings/arrays, defensive copies and runtime validation, documented with JSDoc. No TypeScript or schema-library dependency. All serializable numbers are finite; nonfinite results become explicit failures, never JSON-null substitutions. IDs use lower-case `[a-z0-9][a-z0-9_-]{1,63}`. Bundle/run IDs use browser `crypto.randomUUID()` / Python `uuid4`, never timestamps alone. Unknown keys and unknown schema versions fail closed.

1. `PresentationState = {scale,representation,quality,overlayIds,selectionId,cutPlane,motion}`. Scale `laboratory|construct|cell|tissue-context`; representation `illustration|model-field`; quality `low|balanced|high`; `overlayIds` ≤ 4 registered IDs; `selectionId` null or known object ID; `cutPlane` null or `{axis:'x'|'y'|'z',fraction:0..1}`; motion `system|reduced`. Defaults laboratory/illustration/balanced/no overlays/no selection/no plane/system. Stored separately from scenario /13. Scale changes are discrete representational transitions, not continuous physical zoom or a biological model.
2. `Quantity = {value,unit,origin,sourceIds,uncertainty,missingReason}`. Value finite number or null; origins `synthetic|hypothetical|user-declared-measured|literature|derived`. Null value requires nonempty `missingReason` and null uncertainty; nonnull requires `missingReason: null`. Uncertainty null or `{kind:'interval',lower,upper,unit}` with finite ordered endpoints in the quantity's exact unit enclosing the value; no confidence level invented. ≤ 50 source IDs. Literature requires ≥ 1 resolvable source ID; derived requires run provenance (`context.runId`); user-declared measured stays labelled unverified. Unit allowlist (complete, matching native evaluator outputs): `1` (dimensionless/normalized, always with a semantic label), `Pa`, `Pa*s`, `um`, `mm3/s`, `mm/s`, `1/s`, `m2/s`, `mol/m3`, `mol/(m3*s)`, `1/mm2`, `kg/m3`, `h`, `relative-population`, `count`. No implicit conversion, ever.
3. `FieldDefinition = {unit,type,min,max,nullable,values}` keyed by stable field ID inside `DomainModelDefinition.inputDefinitions/outputDefinitions`. `type` `number|integer|boolean|string|array`; numeric fields carry exact native bounds (null = unbounded) and a known unit or `1` for dimensionless; enumerated strings carry `values`; arrays carry `min/max` length. Definitions describe accepted inputs and declared scalar outputs; the full native evaluator result remains the authoritative output object.
4. `DomainModelDefinition = {id,version,label,domain,inputDefinitions,outputDefinitions,assumptions,boundaryConditions,validityConditions,sourceIds,implementationId,couplingPolicy,supportedOperations}`. Version 1; text fields ≤ 2000 chars, ≤ 50 per list. `couplingPolicy` `independent` for all seven; `supportedOperations` ⊆ `evaluate|sweep|field`. Registered IDs (fixed, no plugin loading): `storyboard`, `slab-oxygen`, `box-oxygen`, `flow-resistance`, `nozzle-shear`, `vascular-supply`, `relative-division`. Cross-reference is an explicit-hypothetical-mapping adapter (not a registered physical model; its identity tests already pin it). Tissue atlas/hardware/recipe catalogs stay reference content, not runnable models.
5. `AdapterEvaluation = {modelId,modelVersion,status,result,quantities,diagnostics,sourceIds,notices}`. `result` is a defensive copy of the exact native result (typed arrays copied, not shared). Status `succeeded|out-of-domain|numerical-failure`: invalid native inputs throw their existing errors; box-oxygen non-convergence → `numerical-failure`, `!inDomain` → `out-of-domain`; nozzle `!laminarAssumptionHolds` → `out-of-domain`; flow native `status:'numerical-failure'` maps through. Legitimate nulls (Krogh not-limiting within its 10 mm cap, division without assumed doubling hours) are `succeeded` with `missingReason`, never coerced. `quantities` maps declared scalar output paths to Quantity records (origin `derived` when built under a run, `synthetic` or `literature` per model definition otherwise).
6. `ModelRun = {schema:'bioprinting-workbench/model-run/1',id,modelId,modelVersion,inputSnapshot,inputSha256,implementationSha256,provenanceStatus,startedAt,finishedAt,status,outputs,diagnostics,sourceIds,notices}`. Status `succeeded|out-of-domain|numerical-failure|cancelled|failed`; timestamps ISO-UTC strings with finishedAt ≥ startedAt. `inputSha256` is the digest of canonical JSON bytes of the complete adapter input snapshot; `implementationSha256` matches the manifest closure digest or is null with `provenanceStatus:'incomplete'` (never a silent pinned claim). `outputs` is the scalar Quantity map; failed/cancelled runs carry empty outputs plus a diagnostic reason. Hashes attest byte identity, not scientific validity.
7. `OverlayDefinition = {id,modelId,representation,unit,legend,coordinateSpace,requiresRun}`. CoordinateSpace `normalized-box|network|illustrative`. Slice fields render only on the normalized-box proxy, never painted onto scaffold geometry; flow edges carry the dimensionless notice; shear/supply are labelled reference panels, not calibrated tissue fields. Selection exposes accessible text/table alternatives. Overlay textures ≤ 256×256; ≤ 4 active overlays; explicit resource ownership.
8. `SweepSpec = {modelId,baseInputs,axes,seed}`: 1–2 numeric axes, 2–10 explicitly listed unique finite values per axis, ≤ 100 total points; box-oxygen limited to resolution ≤ 17 and ≤ 25 points. `SweepResult = {spec,points,summary,status}` with per-point `{inputs,status,run,error}` and completed/failed/total counts. `summarizeSensitivity` reports same-unit ranges and finite-difference slopes only where valid comparable points exist; zero-variance axes report null slope; no probability, causal, viability or efficacy ranking. `seed` is uint32, validated and retained for contract stability (none of the seven models currently uses randomness).
9. `HypothesisCard = {id,revision,title,question,scope,claimBoundary,status,system,mechanism,alternatives,predictions,falsifiers,confounders,missingMeasurements,modelIds,supportingEvidenceIds,contradictingEvidenceIds,queryPlanIds,parentHypothesisIds,authorship,reviewStatus}`. Revision positive integer; title ≤ 300 chars; narrative fields ≤ 3000; lists ≤ 30 items ≤ 500 chars; `alternatives` 2–8 `{id,prediction,falsifier}` (matching ResearchDesk's competing-hypothesis requirement). Status `draft|ready-for-review|archived`; reviewStatus `unreviewed|owner-reviewed` — neither implies scientific validation. Authorship `{createdBy:'owner'|'agent'|'import',method,reviewedBy}`. Missing predictions/falsifiers block ready-for-review but preserve drafts un-fabricated. Contradicting evidence is retained alongside supporting evidence, never silently dropped.
10. `QueryPlan = {id,hypothesisId,query,providerIds,limit,purpose,disclosure,executionStatus}`: query ≤ 500 chars; 1–8 provider IDs; limit 1..10; executionStatus `planned|not-supported`. The Workbench never queues a job; local text stays private unless explicitly selected for exchange.
11. `ResearchExchangeBundle` schema `bioprinting-workbench/research-exchange/1`: `{schema,bundleId,createdAt,producer,sourceRevision,hypotheses,queries,modelRuns,evidence,artifacts,privacyClassification,publicationReviewStatus}`. Producer `{application,version,executedBy}`; sourceRevision `{commit:null|string,dirty:boolean,implementationSha256:null|string}`. Manifest ≤ 5 MiB UTF-8; ≤ 100 hypotheses/queries/runs; ≤ 500 evidence records/artifacts; JSON nesting ≤ 20. Privacy `private|selected-for-exchange`; `publicationReviewStatus` always `not-approved` on import. No secret/note field, executable content or HTML. Cross-language hashing of exchanged records preserves exact producer bytes; semantic comparison is separate and Python/JS float formatting is not assumed identical (golden fixtures use portable numbers).
12. `ArtifactDescriptor = {id,filename,mediaType,bytes,sha256,provenance}`: flat basename `[A-Za-z0-9][A-Za-z0-9_.-]{0,95}`, no dot segments/slashes/drive prefixes/percent-encoded separators; media types `application/json|text/csv|text/markdown|image/png`; ≤ 10 MiB per file, ≤ 25 MiB total selected. Provenance binds model-run/evidence IDs and producer. Verification hashes exact bytes before import; a manifest alone is metadata-only until every selected artifact hash/size matches. No ZIP extraction, no URL fetch, no path opening.
13. `ExchangeImportPreview = {bundleSha256,creates,duplicates,conflicts,warnings,blockedReasons,expectedStoreSha256}`: exact bundle ID+hash duplicates are idempotent; same ID/different hash is a conflict; hypothesis-ancestry reference graph closed and acyclic; unknown model IDs retained as unsupported foreign metadata but never executed/overlaid. Preview performs no writes, submissions or network calls. Apply binds the preview to the current store hash and exact bundle bytes; stale previews reject.
14. `RunReceipt = {id,queryPlanId,deskRunId,status,parameters,submittedAt,finishedAt,artifactIds,failures,submissionSha256}`. Status `planned|queued|running|succeeded|partial|failed|interrupted|submission-unknown`; ambiguous submission responses become `submission-unknown`, never auto-retry. Integrity verification is not scientific validation.
