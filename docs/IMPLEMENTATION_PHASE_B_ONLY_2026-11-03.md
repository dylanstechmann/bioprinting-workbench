[Types]

Use JSDoc and strict runtime validators with plain object records, exact field allowlists, required-key checks, finite bounded numbers, defensive copies, and no TypeScript/schema-library migration. Reuse `assertAllowedKeys`, `assertPlainRecord`, `finite`, and `text` from `/workspace/bioprinting-workbench/src/validation.js` without modifying its existing behavior. Do not coerce strings to numbers or silently default missing required fields. Reject dangerous property names `__proto__`, `prototype`, `constructor` at every new untrusted-record level. IDs match `[a-z0-9][a-z0-9_-]{1,63}`; SHA-256 is lowercase 64 hex characters. Reject duplicates and unknown versions.

1. `UnitId`: exact allowlist `1`, `Pa`, `Pa*s`, `um`, `mm3/s`, `mm/s`, `1/s`, `m2/s`, `mol/m3`, `mol/(m3*s)`, `1/mm2`, `kg/m3`, `h`, `relative-population`. `1` explicitly means dimensionless or normalized and must have a semantic label. Resolution/layers/points/doublings have separate count/coordinate descriptions, not physical units. No converters or assignment of geometry units. Add only units used by registered existing fields.
2. `Quantity = {value,unit,origin,sourceIds,uncertainty,missingReason}`. Numeric value finite or null; origin `synthetic|hypothetical|user-declared-measured|literature|derived`. `sourceIds` is an array of <=50 unique bounded IDs. Literature requires >=1 reference resolved against the model's catalog source allowlist. Measured means user-declared, never reviewed by this software. Null requires nonempty missingReason <=1000 characters, uncertainty null; nonnull requires missingReason null. Uncertainty null or `{kind:'interval',lower,upper,unit}` with finite ordered bounds enclosing value and exact matching unit. A derived quantity requires `context.runId` during validation. No confidence level, calibration, or evidence upgrade inferred.
3. `FieldDefinition = {path,type,unit,semantic,min,max,values,nullable,items}`. Dotted paths identify fixed object fields; paths never execute code. Type `number|integer|boolean|string|array|object`. Numeric fields require a known unit and explicit numeric bounds or null for unbounded; other field units are null. Enum values required for enumerated strings; arrays declare item definition, length bounds via min/max; objects declare nested item definitions. All keys present, irrelevant properties null. Include exact accepted resolution/enum sets and positional layout; descriptive metadata never replaces native validators. Version 1 definitions cover adapter inputs and declared output quantities; raw outputs remain the authoritative full evaluator result.
4. `DomainModelDefinition = {id,version,label,domain,inputDefinitions,outputDefinitions,assumptions,boundaryConditions,validityConditions,sourceIds,implementationId,couplingPolicy,supportedOperations}`. Version 1; definitions are bounded arrays of FieldDefinition; textual statements <=2000 characters, <=50 per list; unique paths. couplingPolicy `independent` for all seven models. supportedOperations only `evaluate` in B; do not advertise future sweep/field integrations. implementationId matches the corresponding generated manifest entry. Return defensive copies; no user-registration/plugin execution API.
5. Seven fixed IDs: `storyboard`, `slab-oxygen`, `box-oxygen`, `flow-resistance`, `nozzle-shear`, `vascular-supply`, `relative-division`. Reference catalogs are not runnable models. Cross-reference appears in documentation as an independent mapping adapter and is covered by dependency/identity regressions, not a new registry entry in B.
6. `AdapterEvaluation = {modelId,modelVersion,status,result,quantities,diagnostics,sourceIds,notices}`. `result` is a defensive copy preserving exact native object structure and typed-array constructors. Status `succeeded|out-of-domain|numerical-failure`; invalid native inputs throw their existing errors. quantities map declared scalar output paths to Quantity records; booleans/enums/fields remain raw results, never forced into numeric quantities. A runId context is required only when creating derived output quantities for a ModelRun; standalone identity evaluations may omit quantities and return an empty quantity map. Explicitly document this distinction. Diagnostics contain bounded scalar/text/boolean/null records, not hidden field data.
7. `ModelRun = {schema,id,modelId,modelVersion,inputSnapshot,inputSha256,implementationSha256,provenanceStatus,startedAt,finishedAt,status,outputs,diagnostics,sourceIds,notices}`. Schema `bioprinting-workbench/model-run/1`. id externally supplied UUID or generated with crypto.randomUUID; timestamps explicit ISO UTC instants, finish >= start. Status `succeeded|out-of-domain|numerical-failure|cancelled|failed`; outputs are scalar quantity map, not raw field arrays. inputSnapshot is a defensive canonical-JSON-compatible copy of complete adapter inputs. Provenance status `pinned|incomplete`; pinned requires both digests and a manifest entry accepted for this model/version; unavailable implementation digest is null and incomplete, never silently trusted. Failed/cancelled runs have empty outputs and an explicit diagnostic reason. SourceIds reference existing catalogs; no biological/review assertion attaches to a hash.
8. `ImplementationManifest = {schema,canonicalization,models}`. Schema `bioprinting-workbench/model-provenance/1`; canonicalization `sorted-json-lf/1`. Each sorted model entry `{id,version,roots,files,implementationSha256}` has sorted unique relative POSIX source paths; files `{path,sha256,bytes}`; roots are adapter entry + evaluator entry (include registry, provenance helper, and validation dependencies when imported). Reject absolute paths, traversal, non-project imports, cycles only if traversal fails to terminate, missing files, dynamic imports, re-exports or syntax unsupported by the audited dependency extractor. Import cycles themselves can be traversed with a visited set. Hash each file's exact bytes; implementationSha256 hashes canonical bytes of `{id,version,roots,files}`. No timestamps, machine paths, manifest self-hash, or unrelated UI modules. The shared adapter module may conservatively cause all seven roots to share a larger closure; document this, do not underhash.
9. Canonical JSON: accepted values null/boolean/finite number/string/dense array/plain record only; reject undefined, BigInt, functions, symbols, accessors, nonenumerable record properties, custom prototypes, sparse arrays, unsupported array properties, dangerous keys, lone surrogate strings, cycles, nonfinite numbers and unsupported typed arrays. Bound recursion <=32, aggregate nodes <=100000, output <=1 MiB. Sort own string keys lexicographically by UTF-16 code units; recursively serialize keys explicitly rather than relying on object enumeration (integer-looking keys reorder). Strings/numbers use JSON.stringify leaf formatting, -0 becomes 0; retain array order; UTF-8, exactly one trailing LF. Permit shared noncyclic references by using an ancestor set. No Unicode normalization or arbitrary float rounding. This is a project-specific JS format, not an RFC canonicalization claim. Future Python exchange hashes original producer bytes; matching floating serialization is not assumed.

New in `/workspace/bioprinting-workbench/src/model-provenance.js`:
- `canonicalJsonBytes(value): Uint8Array`: strict bounded serializer, deterministic leaf encoding and LF; no implicit typed-array conversion.
- `sha256Bytes(bytes): Promise<string>`: only Uint8Array, respect byteOffset/length, do not detach/mutate input; fail explicitly if crypto.subtle unavailable. No insecure fallback.
- `validateModelRun(raw, registry = getDomainModels()): ModelRun`: structural checks, model/version/unit/output path matching, timestamps, source resolution, status/output consistency, defensive copy. Structural validation alone does not verify hashes.
- `verifyModelRun(run, manifest): Promise<{inputMatches,implementationMatches,provenanceStatus}>`: recompute canonical input digest and match manifest model/version; mismatch is explicit failure. A browser-supplied manifest is an integrity reference, not live source attestation.
- `buildModelRun({id,modelId,inputs,startedAt,finishedAt,manifest}, evaluation): Promise<ModelRun>`: require matching model/version and evaluation; hash full inputs; project/validate quantity outputs under id; resolve implementation entry; preserve incomplete state if manifest unavailable. Errors/cancellations must be supplied explicitly, not invented from native exceptions. Do not invoke evaluator inside run construction or hide a second calculation.

New in `/workspace/bioprinting-workbench/scripts/build-model-provenance.mjs`:
